# 전사 생존력 조정 요청 (학습 플랫폼 → Unity 게임)

- 작성: 학습 플랫폼 쪽, 2026-11-22
- 대상 빌드: `QaArena 0.4.0` → 다음 빌드 (0.5.0 권장)
- 우선순위: 높음 (전체 사이클에서 전사 학습 결과가 무의미해짐)

## 문제

0.4.0, 안정형(stable) 기준 (학습 쪽 평가 시드 300판):

| 전사 | 클리어 | 판당 사망 |
|---|---|---|
| 손 튜닝 default | 55% | 3.06 |
| CMA-ES / IMPALA 학습 후 | **0%** | 0.19 |

- 전사는 손 튜닝으로도 **판당 ~3번 죽어야** 보스를 잡는다. 사망 없이 깨는 길이 사실상 없다.
- 안정형은 사망 1회를 10분 손해로 친다 → 학습이 "죽지 말고 시간 초과" 를 택했다.
- 비교: 마법사 손 튜닝 62%·사망 2.75 → CMA-ES 89%·사망 1.75 (학습으로 사망이 줄면서 클리어도 오름). 전사는 이 길이 없다.

학습 쪽은 보상에 **클리어 실패 벌점**(30분)을 추가했다 (결정 A). 게임 쪽에서는 전사가 **적게 죽고도 깰 수 있게** 해 달라는 요청이다 (결정 C).

## 요청

목표 (안정형, 손 튜닝 default 기준): **전사 클리어 ≥ 60%, 판당 사망 ≤ 1.5**, 클리어 시간은 지금 수준(마법사·궁수와 비슷한 400초대) 유지.
"죽지 않고 오래 버티면 결국 깬다" 가 아니라 "생존 행동(가드·후퇴)을 잘 쓰면 덜 죽고 깬다" 가 되게.

방법은 Unity 쪽 판단에 맡긴다. 후보:

1. 전사 생존 블록(가드·방어 자세 등) 효과 강화 — 피해 감소율 또는 지속시간
2. 보스 근접기 피해량 또는 빈도 소폭 하향 (다른 직업에도 영향 — 마법사·궁수 수치 같이 확인)
3. 전사 최대 체력 또는 `armor` 상향 (0.5 → 0.6 등)
4. 전사 비전투 회복 조건 완화

- 학습 쪽이 바꿀 수 있는 파라미터(`describe` 의 optimizable 범위) 안에서 "덜 죽는 조합" 이 존재해야 학습이 그쪽으로 간다.
  손 튜닝 default 만 좋아지고 범위 안에 더 나은 조합이 없으면 학습 결과는 그대로일 수 있다.
- 판 로직의 결정성·프로토콜(v1.2)은 바꾸지 않는다. 데이터가 바뀌면 `game_version` 을 올린다.
- 궁수(100% 클리어, 329s)와 마법사가 너무 쉬워지지 않게 확인.

## 확인 방법 (학습 쪽에서 실행)

```bash
venv\Scripts\python.exe run/run_measure_build.py
```

결과는 `docs/STATUS.md` 3장 표에 한 줄로 추가된다. 확인 기준: 전사 손 튜닝 클리어 ≥ 60%·사망 ≤ 1.5, 학습 후 클리어가 0% 로 떨어지지 않을 것.
