## BT
- burst: 콤보용 Setup(피해 버프·표식)이 준비됐으면 먼저 → Burst. 버프·표식 중이면 필요도 +0.3
- dps: 같은 역할 스킬 중 점수(피해 / max(시전, GCD)) 최대, 동점은 데이터 순서 → 평타
- survival: 물약 / 방어 / 거리 (위험도 항은 evade 로 옮김 → 생존 N 은 0.7.x 와 같은 식)
- **evade** (N = danger): 이동기 쿨이면 사용(안전 지점 쪽 즉시 이동), 아니면 걸어서. 생존과 같은 최대 유지 규칙
- **setup** (N 0.6: Setup 준비 + 버스트가 combo_window 안 / 자원 부족·사거리 안)
- 시전 중 위험도 ≥ `evade_cancel_danger` (w_evade > 0) → 시전 취소 (`cast_cancel` 로그)
- 고친 것: ① 전사 **돌진 0% 원인** = 돌진이 dps 블록 안에만 있었는데 dps 필요도는 사거리 밖이면 후보 제외 → 멀 때 한 번도 평가되지 않음. approach(fallback) 블록에도 넣음 → 매 판 사용. ② 생존 최대 유지(12s → 6s 잠금)가 회피로 잠깐 끊길 때마다 리셋돼 생존에 갇혀 멈춘 판(stall)이 됨 → evade·gimmick 끼어들기는 유지 시간을 끊지 않게.
- 로그: `skill{name, block, role, cooldown_ready_at}`, `combo{setup, burst}`, `cast_cancel{skill, reason}`, `dodge{skill|from/to}`
